# Craig Burke Portfolio

A static, case-study-first Astro 5 portfolio based on the [Case](https://github.com/erlandv/case) theme.

## Commands

- `npm run dev` — start the local development server
- `npm run build` — type check and create the production site in `dist/`
- `npm run preview` — preview the production build

GitHub Actions deploys the `master` branch to GitHub Pages. The custom domain is configured in `public/CNAME`.
